# Oak & Ember Living — Furniture Website

## 1. Project Description

Oak & Ember Living is a responsive furniture business website designed to display furniture products and provide information about the business.

## 2. Project Structure

- `index.html` — Home page
- `about.html` — About Us page
- `products.html` — Products page
- `categories.html` — Furniture categories
- `gallery.html` — Furniture image gallery
- `contact.html` — Contact Us page
- `README.md` — Project documentation
- `images/` — Folder containing furniture pictures

## 3. Technologies Used

- HTML5
- Tailwind CSS
- Tailwind CSS CDN

## 4. Design Colours

- Ember Brown: #B86B45
- Forest Green: #28483D
- Cream: #F7F3EC
- Dark Ink: #202923

## 5. How to Run the Website

1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. Navigate through the website using the navigation menu.
4. Ensure you have an internet connection for Tailwind CSS CDN.

## 6. Cloudinary MCP

The VS Code workspace config in `.vscode/mcp.json` connects to Cloudinary's hosted Asset Management MCP server. Open the project in VS Code and approve/start the server when prompted; complete Cloudinary authentication if requested. Credentials are not stored in this repository.

## 7. Deploy to GitHub Pages

The site is published at <https://shikhu-1.github.io/Oak_and_Ember_Furniture/>. GitHub Pages is already configured to deploy the repository. Push changes to the `main` branch to trigger a deployment, and check the repository's **Actions** tab for its result. If Pages is not enabled, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.
